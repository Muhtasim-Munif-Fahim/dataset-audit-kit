# Contributing to Dataset Audit Kit

Thank you for helping improve this project.

## Setup

```bash
git clone https://github.com/Muhtasim-Munif-Fahim/dataset-audit-kit.git
cd dataset-audit-kit
pip install -r requirements.txt
```

## Development Loop

1. Create a branch for your change.
2. Add or update tests.
3. Run the full suite with `python -m pytest -q`.
4. Run the demo script with `python examples/demo.py`.
5. Open a pull request with a clear summary.

## Good Contributions

- New validation checks.
- Better CLI output and formatting.
- Notebook or documentation improvements.
- Bug fixes with regression tests.

## Reporting Issues

Please include:

- Python version
- Operating system
- Dataset shape
- Reference dataset details, if relevant
- The exact CLI command or Python snippet you ran
